SuperFly 品牌简介

服务定位

SuperFly 将机场订阅与客户端加速器结合：购买套餐后即可获得订阅链接，在 Windows、macOS、Android、iOS 及常见第三方客户端中导入，用于网页访问、流媒体解锁与游戏线路优化。服务强调可预期的流量配额、同时在线设备数，以及可对照的官方下载入口，避免来源不明的安装包。

节点与线路

节点池覆盖香港、东京、新加坡、洛杉矶、伦敦等常用区域，旗舰版与团队版包含 IPLC 专线游戏优化与更高带宽 VIP 节点。普通线路适合日常浏览与基础流媒体；专线适合对延迟更敏感的会议与对战。SuperFly 不把“无限速度”作为承诺，而是按套餐给出流量与设备上限，便于长期规划。

客户端选择与官方下载

SuperFly 的使用核心是“订阅 + 客户端”。请优先在本页完成官方下载对照，再把订阅链接导入对应应用。不同系统可并行使用，但需遵守套餐的同时在线台数。

桌面端：Windows 与 macOS

Windows 建议使用 SuperFly 官方客户端或兼容 Clash 内核的图形界面，导入订阅后可按地区、延迟或负载筛选节点。macOS 可使用官方客户端，也可配合 Surge、Clash Verge 等工具。桌面端适合长时间挂机、分流规则与游戏加速。官方安装包入口：SuperFly Windows 客户端下载、SuperFly macOS 客户端下载。

移动端：Android 与 iOS

Android 可安装 SuperFly 官方应用或兼容 Clash Meta 的客户端，适合在蜂窝网络与 Wi-Fi 间切换。iOS 常用 Shadowrocket、Stash、Quantumult 等导入订阅；请通过本站说明核对配置字段，避免错误的混淆订阅。移动端入口：Android 官方下载、iOS 导入说明。

第三方兼容与路由器

SuperFly 机场订阅遵循常见 Clash / Surge 格式，可在支持订阅更新的客户端中自动拉取节点。家庭或工作室如需整网加速，团队版可配合定制路由，将指定网段走 IPLC 或高带宽节点。下载与文档均以 SuperFly 官网为准，不通过第三方网盘分发安装包。

使用场景

跨境办公与资料访问

远程会议、代码仓库、文档协作对稳定性要求高于峰值带宽。基础版即可覆盖轻度办公；频繁切换地区或同时开多台电脑时，旗舰版的 5 设备与优先工单更合适。

流媒体与内容研究

基础版提供基础流媒体解锁，旗舰版强调全节点原生解锁，减少因公共出口导致的播放失败。建议在客户端中为视频域名单独分流，避免全局模式占用过多流量。

游戏加速

旗舰版含 IPLC 专线游戏加速优化，团队版另有 VIP 高带宽节点。对战类应用请固定一条延迟稳定的线路，而不是频繁自动切换。SuperFly 将游戏场景放在专线套餐中，而不是所有套餐均一概而论。

操作说明

获取机场订阅

在官方网站选择套餐并完成开通后，账户页会给出订阅地址。请复制完整链接，不要截断参数。订阅用于客户端拉取节点列表，本身不是“一个节点密码”。

导入客户端

打开已下载的 SuperFly 客户端或兼容应用，选择“从 URL 导入”或“订阅管理”，粘贴链接并更新。首次导入后建议手动测速，将常用地区置顶。iOS 第三方客户端需在配置中确认 DNS 与分流模式，以免出现只能打开部分网站的情况。

日常使用与设备管理

同一套餐可在多台设备登录，但同时在线受套餐限制：基础版 3 台、旗舰版 5 台、团队版 20 台。流量按自然月重置。若某个客户端频繁重连，优先更换节点组或检查本地系统代理端口占用，而不是重复下载安装包。

常见问题

SuperFly 是什么？和普通 VPN 有何不同？

SuperFly 是机场订阅与 VPN 加速器结合的服务：你购买的是带流量与设备上限的订阅，可在多款客户端中导入节点。相对单一 App 内置线路，机场模式更方便按系统选择客户端，并把分流规则留在本地。

如何完成 SuperFly 客户端下载？

请只通过本站「客户端选择与官方下载」区块进入对应系统入口。Windows 与 Android 提供官方安装包，macOS 提供官方客户端，iOS 以兼容应用导入订阅。不要使用来路不明的镜像，以免订阅被替换。

机场订阅链接怎么导入？

复制账户中的订阅 URL，在客户端的订阅或配置页面粘贴并更新。Clash 系选择对应 YAML/订阅类型，Surge 与 Shadowrocket 选择 HTTPS 订阅。导入成功后应看到按地区分组的节点，而不是空白列表。

基础版、旗舰版和团队版如何选择？

轻度浏览与 3 台设备内使用选基础版。需要原生流媒体、游戏专线或 5 台设备选旗舰版。工作室、教室或需要定制路由、专属客户经理时选团队版。年付适合已经固定客户端方案的用户。

SuperFly 是否支持流媒体解锁与游戏加速？

基础版支持基础流媒体；旗舰版提供全节点原生流媒体解锁，并包含 IPLC 专线游戏加速优化。团队版在此之上提供 VIP 高带宽节点。实际播放与对战仍取决于当地出口与客户端分流是否正确。

流量用完或设备超限怎么办？

当月流量用尽后新连接会受限，可等待下月重置或升级套餐。同时在线超出上限时，较早的会话可能被挤下线。建议在不常用的设备上关闭系统代理，把名额留给正在使用的电脑与手机。
